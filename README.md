# Roblox Chat Settings Editor
An app created by Defacube [watchr] that lets you bypass your Roblox chat settings.
This can be used to bypass Roblox's Middle-East restrictions, and most likely the whispering restrictions for <13 users. To do so:
1. Install gamejoin-roblox.pfx into Trusted Root Certification Authority (password is xd)
2. Run middleeastbypass.exe as Administrator
3. Launch Roblox through the app.
4. Set both options to AllUsers
5. Done! When you join a game, the chatbox won't show, however you will be able to type by pressing "/" on your keyboard.
